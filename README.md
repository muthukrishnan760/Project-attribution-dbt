# Real-Time Attribution Dashboard

CustomerLabs Data Engineer Assessment.

## Project Goal

Build a near-real-time customer attribution pipeline that
calculates First-Click and Last-Click attribution.

## Planned Technology Stack

- Google BigQuery — cloud data warehouse
- GA4 public dataset — source event data
- dbt — SQL transformation and data modeling
- Python — event generation and streaming
- Streamlit — realtime dashboard
- Git — version control

Environment setup in progress.
